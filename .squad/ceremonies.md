# Sprint Ceremonies

## Standup
- **When:** Start of each working session
- **Who:** @Gandalf reads `.squad/decisions.md` and `.squad/identity/now.md`
- **Output:** Updated `now.md` with current focus

## Planning
- **When:** Start of each sprint/milestone
- **Who:** @Gandalf + @Elrond
- **Output:** Task breakdown, agent assignments, updated routing if needed

## Retrospective
- **When:** End of each sprint/milestone
- **Who:** All agents via @Gandalf
- **Output:** Updated `.squad/identity/wisdom.md` with learnings

## Code Review
- **When:** Before merging any PR
- **Who:** @Aragorn (test coverage) + domain owner agent
- **Output:** Review comments, approval/rejection
