# G-mathPOC — The Fellowship of Learning

## Project
**G-mathPOC** — A multilingual math learning web platform (Hebrew → English → Arabic) targeting high school students and above.

## Stack
- **Frontend:** React 18+, TypeScript, i18next, MathJax/KaTeX
- **Backend:** Python, FastAPI, SQLAlchemy
- **Infrastructure:** Docker, GitHub Actions, nginx

## Project Context
- Hebrew-first with RTL layout, expanding to English (LTR) and Arabic (RTL)
- Mathematical formula rendering required (MathJax or KaTeX)
- Accessibility compliance (WCAG 2.1 AA minimum)
- Multi-language content requires robust i18n architecture
- Target audience: high school students and above
