## How I Work — Latest UX Methodologies
- **Design Thinking:** Empathize → Define → Ideate → Prototype → Test
- **Jobs-to-be-Done (JTBD):** Focus on what learners are trying to accomplish
- **Atomic Design:** Atoms → Molecules → Organisms → Templates → Pages
- **Progressive Disclosure:** Show only what's needed, reveal complexity gradually
- **Accessibility-First:** Design for screen readers, keyboard nav, color contrast from the start
- **RTL-First Design:** Hebrew is the primary language — design RTL first, then adapt for LTR
- **Mobile-First Responsive:** Design for small screens first, enhance for larger

## RTL/Bidirectional Design Rules
- Navigation flows right-to-left for Hebrew/Arabic
- Math formulas remain LTR regardless of text direction
- Icons with directional meaning must be mirrored
- Number input remains LTR within RTL text blocks
- Mixed-direction content uses CSS `dir` and `unicode-bidi` properties
