📌 מה זה G-Math?

G-Math היא פלטפורמת לימוד מתמטיקה אינטראקטיבית, המיועדת לתלמידי תיכון ומעלה.

הפלטפורמה תהיה פתוחה לכולם (ללא רישום) ותכלול מצגות, דפי עבודה ופעילויות אינטראקטיביות בכל נושא.

שפה ראשונית: עברית — בהמשך גם אנגלית וערבית.

הפלטפורמה מבוססת על האתר הקיים www.g-math.co.il ומשדרגת אותו עם טכנולוגיה מודרנית.

🏗️ מבנה התוכן

הפלטפורמה בנויה ב-3 רמות:

📁 נושא ראשי (9 קבועים) → 📂 נושא משנה (ניתן לעריכה) → 📄 שיעור (ניתן לעריכה)

כל שיעור יכול לכלול:

  • מצגת HTML (מיובאת)
  • דף עבודה אינטראקטיבי
  • פעילות GeoGebra

📊 סטטוס נוכחי

  • ריפוזיטורי GitHub — נוצר ומוכן הושלם ✓
  • צוות פיתוח (Squad) — 10 סוכנים מוגדרים עם תפקידים, מודלים וחוקים הושלם ✓
  • ארכיטקטורת מערכת — מסמך מלא (סכמת DB, API, frontend, backend) הושלם ✓
  • שלד הפרויקט — React + FastAPI + Docker + nginx הושלם ✓
  • דמו ויזואלי — דף בית עם 9 כרטיסיות נושאים, navbar, דפי נושא עם אקורדיון בעבודה
  • עיצוב UX מלא — תכנון חוויית משתמש לכל הדפים מתוכנן
  • Backend API — חיבור לבסיס נתונים ומערכת ניהול תוכן מתוכנן
  • העלאת תוכן — מצגות, דפי עבודה ופעילויות מתוכנן

⚙️ טכנולוגיות

  • Frontend: React 18 + TypeScript + Vite
  • Backend: Python FastAPI
  • בסיס נתונים: PostgreSQL
  • שפות: עברית (ראשי), אנגלית, ערבית — מנוהל עם react-i18next
  • כיוון: RTL (ימין לשמאל) כברירת מחדל
  • Containers: Docker Compose (frontend + backend + DB + nginx)
